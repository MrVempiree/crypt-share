Security notes

        
    
          
  • The URL fragment after # is not sent to a web server in normal HTTP requests.
    • 
          
  • Encryption and decryption happen locally with WebCrypto AES-GCM and PBKDF2-SHA-256.
    • 
          
  • Expiry and burn-after-reading are client-side controls. They cannot erase copied links, screenshots, or notes saved by a reader.
    • 
          
  • There is no account recovery. If the passphrase is lost, the note cannot be decrypted.
